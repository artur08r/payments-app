# payments-app

Фронтенд платёжного кабинета: «Платежи и переводы» и «История». Бэкенда пока нет, данные моковые (`src/data/mock.ts`).

## Принцип работы

1. **Пишем локально** — код правим на этом компьютере в `~/Claude/payments-app`.
2. **Проверяем локально** — запускаем в Docker и смотрим в браузере на http://localhost:5173. Всё должно работать до коммита.
3. **Пушим в git** — только проверенное: коммит → `git push` в `github.com/artur08r/payments-app` (приватный, ветка `main`).

Локальная папка и GitHub всегда синхронизированы: не оставляем непушнутых проверенных изменений.

## Запуск

Всё крутится в одном контейнере (Node + Vite dev-сервер с hot reload, папка проекта примонтирована внутрь). Node на компьютер ставить не нужно.

```bash
docker compose up -d --build   # запустить
docker compose logs -f web     # логи
docker compose down            # остановить
```

После изменения `package.json` — пересобрать: `docker compose up -d --build --renew-anon-volumes`.

## Страницы

- `/` — Платежи и переводы. Переключатель «Платежи / Переводы» на этой же странице (`/?tab=transfers`).
- `/transfers/phone`, `/transfers/card`, `/transfers/own` — формы переводов: по номеру телефона, по номеру карты, между своими счетами. Открываются с плиток во вкладке «Переводы». Общие куски форм — `src/components/transfer.tsx`. Отправка пока моковая: показываем экран «Перевод отправлен», балансы не меняются.
- `/history` — История операций, сгруппированная по дням.
- Навигация между ними — в шапке сверху.
